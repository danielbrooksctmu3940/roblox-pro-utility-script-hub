## Overview

Roblox Pro Utility is a portable Windows utility for Roblox that provides a Lua script executor and a compact workspace for managing custom scripts. The built-in editor supports syntax highlighting, and injection timing can be adjusted through the available configuration controls.

Alongside script execution, the tool brings together features frequently associated with Roblox utilities, such as aimbot settings, silent aim, ESP overlays, movement options, auto-farm tools, and FPS unlocking. It runs directly from its application folder and does not follow a standard installation process.

## Included Capabilities

- Write and run custom Lua scripts through the integrated syntax-highlighted editor.
- Control script injection with a configurable delay.
- Adjust aim assistance using field-of-view and smoothing options.
- Support silent aim for compatible script setups.
- Show box ESP overlays containing names, health bars, and distances.
- Use fly, speed, noclip, and infinite-jump movement features.
- Set up auto-farm routines for supported Roblox experiences.
- Unlock FPS and optionally inject automatically when a game starts.
- Run the software as a portable folder-based application.
